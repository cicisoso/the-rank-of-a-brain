# Four-connectome analyses (v2.0.0, PLOS Computational Biology submission)

Scripts, derived data and results for *"Cell types set the effective rank of four complete Drosophila connectomes"*. The run order, raw-data sources and dependencies are in the top-level README ("v2.0.0 pipeline").

| Path | What it holds |
|---|---|
| `p1_prep.py` … `p9_precise_pr.py` | Analyses, numbered in run order (`p7` was a linear-dynamics analysis that was dropped and is not included). |
| `fig1_rank.py` … `fig5_patches.py`, `figsupp_plos.py`, `figlib_plos.py` | Figs 1–5 and S1–S3 Figs. |
| `make_tables.py` | `tables/S1_Table.xlsx` (every number behind the figures and text) and `results/table1.md` (Table 1). |
| `data/` | BANC v888 (whole CNS) and MANC v1.0 (traced neurons) node tables and synapse-count matrices, pairs with ≥5 synapses. |
| `results/` | `pr_table.json` (1,024-probe effective ranks, 15 networks, both weightings), `spectrum_*.json` and `spectra_*.npz` (BANC and MANC spectra and nulls), `types_banc_manc.json` and `block_precise.json` (cell types), `sex_individual.json`, `similarity.json` and `sex_mode.json` (sex versus individual), `patch_*.json` and `containment_*.npz` (sex-specific neurons), `robustness.json` (thresholds, weights, estimator validation), `scaling_modes.json` (rank scaling and mode localisation). |
| `figures/` | Figures in PDF and PNG (the LZW TIFF files for submission are regenerated by the figure scripts). |
| `tables/` | S1 Table. |
